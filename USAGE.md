# Инструкция по использованию

## Быстрый старт

### 1. Добавить продавца

Запустите скрипт и введите ссылку на товар Wildberries или артикул:

```
python scripts/add_seller.py
```

Пример:
```
Введите ссылку или артикул WB: https://www.wildberries.ru/catalog/12345678/detail.aspx
```

Или просто артикул:
```
Введите ссылку или артикул WB: 12345678
```

Скрипт сам найдёт продавца и добавит его в список отслеживания.

### 2. Проверить новых товары

```
python scripts/check_all.py
```

Скрипт проверит всех продавцов и покажет, какие новые товары появились.

### 3. Запустить Telegram-бота

```
python scripts/run_bot.py
```

Бот с меню управления:
- 📋 Список продавцов — просмотр, включение/отключение, удаление
- ➕ Добавить продавца — по ссылке или артикулу
- 🔍 Проверить новинки — ручная проверка
- 📤 Опубликовать пост — генерация + предпросмотр + подтверждение
- 📊 Статистика — количество продавцов, публикаций, настройки
- ⚙️ Настройки — изменение режима отбора, рейтинга, цены
- ⏱ Планировщик — автоматическая проверка по расписанию

## Docker

### Требования
- Docker Engine 24+
- Docker Compose v2

### Запуск

1. Скопируйте `.env.example` в `.env` и укажите ваш токен:
```bash
copy .env.example .env
# Отредактируйте .env — укажите BOT_TOKEN
```

2. Соберите и запустите:
```bash
docker compose up -d
```

3. Посмотреть логи:
```bash
docker compose logs -f
```

4. Остановить:
```bash
docker compose down -v
```

### Как это работает
- Контейнер автоматически перезапускается при падении (`restart: always`)
- База данных и логи сохраняются в папке `data/` на хосте
- Chromium для Playwright предустановлен в образе
- Переменные окружения берутся из `.env` файла

## Настройки

Все настройки изменяются через Telegram-бота (меню "⚙️ Настройки"):

| Параметр | По умолчанию | Описание |
|----------|-------------|----------|
| Режим отбора | `mixed` | `popular` / `new` / `mixed` |
| Мин. рейтинг | `4.7` | Минимальный рейтинг товара |
| Макс. цена | `3500` | Максимальная цена |
| Товаров за раз | `2` | Сколько товаров публиковать за раз |
| Интервал проверки | `6` | Часов между автоматическими проверками |

### Режимы отбора:
- **`popular`** — товары с наибольшим количеством отзывов
- **`new`** — новые товары (20-300 отзывов)
- **`mixed`** — сбалансированный режим

## Типичный рабочий процесс

1. **Запускаете бота**: `python scripts/run_bot.py` (или `docker compose up -d`)
2. **Добавляете продавцов** через меню бота
3. **Настраиваете параметры** отбора через меню
4. **Запускаете планировщик** — бот сам проверяет товары каждые N часов
5. **Присылает предпросмотр** — вы подтверждаете публикацию
6. **Готово!** Пост в канале @wbuppp

Повторный запуск не создаст дубликатов — система запоминает опубликованные товары.
