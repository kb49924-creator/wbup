# Changelog

## [2.1.0] - 2026-09-01

### Добавлено
- Переключение тёмной/светлой темы с сохранением в localStorage
- Стэк toast-уведомлений (до 5 одновременно, с анимациями появления/скрытия)
- Health Check эндпоинт (`/api/health`) + индикатор связи в реальном времени в NavBar
- Информационный блок "О системе" с версией, аптаймом, версией Python и размером БД
- Форматирование цен с разделителями тысяч (`12 345 ₽`) в каталоге
- Защита от дублирования запросов (debounce на критических кнопках)
- GZip сжатие ответов сервера (минимальный порог 500 байт)
- Security-заголовки (`X-Content-Type-Options: nosniff`, `X-Frame-Options: SAMEORIGIN`, `Referrer-Policy`)
- Логирование медленных запросов (> 1.0 сек)
- OpenAPI теги и русские docstrings для всех эндпоинтов Swagger UI
- Поддержка добавления продавца по числовому `supplier_id`
- Эндпоинт деталей продавца (`/api/sellers/{supplier_id}/details`)
- История публикаций (`/api/publications`)
- Экспорт каталога товаров в JSON (`/api/products/export`)
- Файл `robots.txt` для блокировки поисковой индексации API
- Skeleton-загрузка карточек каталога
- Клавиатурные сокращения (`Escape` — закрыть модалку, `Ctrl+K` / `Cmd+K` — фокус на поиск, `Ctrl+R` — обновить)
- Закрытие модального окна по клику на фон
- Обновление заголовка вкладки браузера при переключении разделов
- Автоматическая прокрутка наверх при смене вкладки
- Бейдж количества товаров на вкладке каталога
- Бейдж количества продавцов в заголовке списка
- Относительное время ("5 мин назад", "только что") для дат добавления продавцов
- Пульсирующая анимация для статус-индикаторов и бейджей
- Улучшенные hover-эффекты для карточек товаров (подъём + тень)
- Стилизация скроллбара (тонкий, тематический)
- Стили для печати (скрытие навигации и модалок)
- Тултипы для кнопок навигации
- Favicon с эмодзи 📦
- Meta-теги viewport, description, theme-color

### Улучшено
- Модальное окно удаления продавца показывает ID и предупреждение о необратимости
- Улучшены responsive-стили для планшетов и мобильных телефонов (адаптивная сетка карточек)
- Стилизация консоли логов (monospace шрифт, цветные статусы)
- Startup-баннер сервера выводит информацию о Python, FastAPI, OS и директориях
- Автоматическая инициализация схемы базы данных при старте сервера
- Заменены устаревшие вызовы `req.dict()` на `req.model_dump()`

### Исправлено
- Исправлена транслитерация и битые символы в справке `main.py`
- Удалены дублирующиеся импорты в `server.py`
- Добавлен фокус-контур `*:focus-visible` для доступности

## [2.0.0] - 2026-08-15

- Локальный ИИ для умного ранжирования фото товаров
- Веб-интерфейс в стиле Material Design 3 Dark Theme
